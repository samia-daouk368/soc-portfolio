# SOC Analyst Portfolio

This repository is my personal learning portfolio as I work toward a role as a SOC (Security Operations Center) Analyst. It contains notes and write-ups from hands-on cybersecurity training, organized by topic. Each topic pairs a full notes file (detailed, task-by-task write-up) with a condensed cheat sheet (commands, terms, and quick references).

## Skills & Tools Covered

• Offensive & defensive security fundamentals (pentesting concepts, SOC operations, threat intel, DFIR)

• Operating systems: Windows and Linux fundamentals, command line basics

• Networking: OSI model, DNS, HTTP, LAN/packet fundamentals

• Active Directory: users, groups, GPOs, domains, and forest/trust concepts

• Scripting & data basics: Python, JavaScript, SQL fundamentals

• Security concepts: CIA triad, cryptography basics, incident response metrics

• Tools used in labs: dirb, gobuster, hydra, PowerShell, Linux CLI utilities
